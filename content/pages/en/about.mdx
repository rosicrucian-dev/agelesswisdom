# About

This project was created to centrally organize the early curriculum of Paul Foster Case and present the lessons in a more accessible format for the modern era. The source material for these lessons was generously contributed by Tony DeLuce.

This website is a project of [Rosicrucian Developers](https://rosicrucian.dev). For questions, contact the lead developer, [Jonathan](https://rosicrucian.dev/jonathan).
